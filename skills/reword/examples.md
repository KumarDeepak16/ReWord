## 1. Style Match

**User:** `my style: so basically my phone is ok but battery is the main problem, it dies by 6 pm. camera is good for the price and i like the screen also. but it heats alot when i play bgmi so i dont play long`

**Style Print:** Opens with "so basically". Short sentences joined with "but" and "so". Lowercase, no comma before "and", "also" at the end, "alot", no apostrophes. Keep these habits or clean them?

**User:** `clean. 5 marks: what is inflation`

> Inflation basically means prices of things go up over time, so the same money buys less. In India it is measured by CPI and the RBI tries to keep it near 4%. It happens when demand is more than supply or when costs like fuel go up and companies pass it on to buyers. For a common man the effect is direct. Salary stays the same but milk, petrol and rent go up. Savings in the bank also lose value if the interest rate is lower than inflation. So a little inflation is fine for growth but high inflation hurts the common man the most.

Kept: "basically", "so" and "but" links, "also", no comma before "and", the plain way of thinking. Cleaned: capitals, apostrophes, "alot".

## 3. Exam answer (2 marks)

**User:** `2 marks: what is a cache`

> A cache is a small and fast memory that keeps data the computer uses often, so it does not have to fetch it from slow storage every time. For example the browser saves images of a site you visit daily so the page opens faster next time.
